If this workload legitimately requires higher privileges:

In OpenShift, developers cannot self-escalate. A cluster-admin must associate the workload's ServiceAccount with an elevated SCC.

1. Fast CLI Grant (Cluster Admin): 
oc adm policy add-scc-to-user anyuid -z default -n prod-workloads
2. Declarative GitOps RoleBinding (Recommended): 
apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata:
  name: system:openshift:scc:anyuid
  namespace: prod-workloads
subjects:
- kind: ServiceAccount
  name: default
  namespace: prod-workloads
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: system:openshift:scc:anyuid
